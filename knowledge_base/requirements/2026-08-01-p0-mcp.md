# P0-③ MCP 开放接口

## 需求背景
差距分析指出：2026 年 Wind / 同花顺已开放 MCP（Model Context Protocol）供外部 Agent 调用；
本系统虽有丰富分析 API，但缺少标准化 Agent 开放接口。需将公司/产业链/因子挖掘/回测/分析
能力暴露为标准 MCP server，使 Claude Desktop / Cursor / 自研 Agent 可直接调用。

## 实现（已落地，零外部依赖）
1. **工具清单** `mcp/tools_spec.py`：8 个 tools（JSON Schema）
   - list_companies / get_company / list_industry_chains / get_industry_chain
   - get_factor_mining_results / run_factor_mining / run_backtest / agent_chat

2. **MCP server** `mcp/server.py`：标准 MCP over stdio（JSON-RPC 2.0）
   - 实现 initialize / tools/list / tools/call（含 notifications/initialized 忽略）
   - 内部通过本系统 REST API（`http://127.0.0.1:8000/api/v1`）桥接，复用全部已验证逻辑
   - 零外部依赖（仅标准库 urllib）

3. **入口** `mcp/__main__.py`：`python -m mcp.server` 启动 stdio server。

4. **REST 清单端点** `api/v1/endpoints/mcp_gateway.py` + router 注册：
   `GET /api/v1/mcp/manifest` 返回工具清单与接入说明（Web/Agent 发现用）。

## 验证
- stdio 客户端实测：initialize→serverInfo 正确；tools/list→8 工具；
  tools/call(get_company code=300750)→返回真实公司数据(name 字段存在)；
  tools/call(get_factor_mining_results active_only=true)→返回挖掘结果（无 error）。
- REST：`GET /api/v1/mcp/manifest` 返回 server=dsa-mcp、8 tools。
- 外部 Agent 接入方式：`python -m mcp.server`（stdio），或配置到 Claude Desktop/
  Cursor 的 mcpServers（command 指向该启动命令）。

## 备注
- 后端启动需 ~10s（新导入 + LiteLLM 远程模型价目表拉取超时降级），health 复测正常。
- run_backtest / agent_chat 为 best-effort 桥接，参数细节以对应 REST 端点 schema 为准；
  调用失败会返回 error 文本而非中断 MCP 协议。
- 后续可增强：SSE/HTTP transport、鉴权、按用户权限过滤 tools。
